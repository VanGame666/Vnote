# 客户问题反馈

> 问题1: THS信号传输异常

<mark>确保,WIFI名称,WIFI密码,服务器IP地址和端口正确,确保WIFI信号手机显示至少大于等于三格,信号良好</mark>

| 现场现象 |                                                                                            THS信号传输异常, 重启光猫后, THS传输恢复                                                                                             |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 可能原因 | 1. 光猫NAT转换表资源耗尽,拒绝设备的新端口请求 <br>2. THS设备多次重连, 多次申请光猫NAT资源, 导致光猫工作异常 <br>3. 光猫的主要职能是光电转换,WIFI路由性能不足                                                                          |
| 排查措施 | 1. 使用新设备软件连接光猫WIFI,若能正常上网,则说明光猫NAT资源未耗尽 <br>2. 检查WIFI功能是由光猫执行的,还是专门的WIFI路由器执行的,因为光猫的主要作用是用来网络信号的光电转换,WIFI路由功能一般,可能不适合多设备的连接管理,需专门的WiFi路由器 |
| 解决措施 | 1. THS设备重新设计优化连接策略,不要给光猫路由过多的资源申请负担, 每次重连务必向光猫释放之前申请的NAT资源 <br>2. 更换性能中等的WIFI路由器, 光猫设置为桥接模式不是路由模式,不要使用光猫的WIFI路由功能                                      |


| 现场现象 |                                                          THS信号传输异常, 服务器网页无法登入                                                           |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 可能原因 | 1. 服务器程序异常未能正常打开端口,导致THS无法连接服务器,传输异常,也无法导入服务器网页查看数据,因为THS和THS监测网页都依靠服务器程序的正常运行                 |
| 排查措施 | 1. 在局域网内其他电脑ping服务器ip的连通性,若能ping通,则再次telnet 服务器ip和端口,查看服务器端口是否正常打开,再次确定是否TSH传输异常时,服务器监测网页无法打开 |
| 解决措施 | 1. 服务器端软件优化                                                                                                                                    |
