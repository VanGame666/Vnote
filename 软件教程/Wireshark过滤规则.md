# Wireshark过滤规则

## 过滤器类型
1. **捕获过滤器**：在抓包前设置，只捕获符合条件的流量。
2. **显示过滤器**：抓包后对已捕获数据进行筛选，语法更灵活。

## 常用显示过滤表达式

### IP地址过滤
- `ip.addr == 192.168.1.1`：显示源或目的IP为192.168.1.1的所有流量。
- `ip.src == 192.168.1.1`：仅显示源IP为192.168.1.1的流量。
- `ip.dst == 192.168.1.1`：仅显示目的IP为192.168.1.1的流量。

### 端口过滤
- `tcp.port == 80`：显示TCP 80端口的流量。
- `tcp.srcport == 80`：仅显示TCP源端口为80的流量。
- `tcp.dstport == 80`：仅显示TCP目的端口为80的流量。
- `udp.port == 53`：显示DNS相关流量。

### 协议过滤
- `tcp`：只显示TCP协议数据包。
- `http`：只显示HTTP协议数据包。
- `icmp`：只显示ICMP协议数据包（ping命令）。
- `dns`：只显示DNS协议数据包。

### HTTP过滤
- `http.request.method == "GET"`：只显示HTTP GET请求。
- `http.request.method == "POST"`：只显示HTTP POST请求。
- `http.request.uri contains "login"`：显示URI包含"login"的HTTP请求。

### TCP标志位
- `tcp.flags.syn==1 && tcp.flags.ack==0`：只显示SYN包（连接请求）。
- `tcp.flags.syn==1 && tcp.flags.ack==1`：只显示SYN-ACK包（连接响应）。

### 内容过滤
- `frame contains "password"`：查找包含"password"字符串的数据包。
- `tcp contains 92:00:00`：查找包含特定十六进制值的数据包。

## 逻辑运算符组合
- **与**：`and` 或 `&&`（例如：`ip.addr == 192.168.1.1 and tcp.port == 80`）
- **或**：`or` 或 `||`（例如：`tcp.port == 80 or tcp.port == 443`）
- **非**：`not` 或 `!`（例如：`not arp` 排除ARP协议）

## 实用技巧
1. **快速应用过滤器**：在数据包详情面板右键点击字段，选择"应用为过滤器"。
2. **保存常用过滤器**：在过滤器栏右侧点击"Save"保存常用表达式。
3. **颜色标识**：不同协议有不同颜色，可在"视图→着色规则"中自定义。
4. **跟踪流**：右键TCP/UDP数据包选择"跟踪流"，查看完整会话。
5. **统计功能**：使用"统计"菜单查看协议分布、会话统计等信息。

## 捕获过滤器示例
- `host 192.168.1.1`：只捕获与该IP相关的流量。
- `port 80`：只捕获80端口的流量。
- `tcp port 443`：只捕获443端口的TCP流量。

## 注意事项
- 显示过滤器输入框变绿色表示语法正确，红色表示错误。
- 字符串过滤需加英文双引号。
- 协议名称需小写（如`http`而非`HTTP`）。
- 捕获过滤器语法更简洁，功能有限；显示过滤器功能更强大。
